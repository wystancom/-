《谁是男娘》手机玩法 Demo

打开方式
1. GitHub Pages：完整上传 index.html、styles.css、game.js 与 assets/characters 文件夹，然后访问 Pages 生成的链接。
2. 本地离线试玩：双击 START_GAME.html；开发调试可通过本地网页服务打开 index.html。
3. 建议使用 Chrome、Edge 或 Safari，并把窗口调成手机竖屏比例。

玩法
- 主画面是一块全屏棚拍取景器：直接点人物身上的发光焦点进行观察。
- 资料与对话收在底部抽屉里，展开时才显示；画面上方只保留局数、信任、报酬与收藏数。
- 每位来访者最多调查 4 次：观察焦点、核对资料、对话交流。
- 至少调查 3 次后，判断 Ta 是否属于本游戏的“男娘”范畴；单条线索不会直接给答案。
- 本游戏判定规则：男性角色只要以女装或明显女性化造型出镜，就属于“男娘”；Ta是否喜欢或接受这个称呼，不影响答案。
- 可靠答案需要“男性信息＋本次女装呈现”两类证据组合；声音、骨架、身形与服装尺码不是可靠依据。
- 越界问题会降低信任，信任与证据质量都会影响报酬。
- 判断正确会解锁一张本人授权的企划写真，并播放玫瑰柔光、心形与花瓣闪点；判断错误会有“啪”的全屏掌印拍击，随后淡化并永久留在本局画面上，但不拦截后续点击。
- 结算页与取景器顶部均可进入角色相册；已解锁图鉴会保存在当前浏览器，可点开大图、切换特写及浏览上一张/下一张。
- 完成 9 位角色后可进入“夜间小屋”：摄影报酬会进入持久钱包，可购买胶卷花束、香氛蜡烛与定制相册提升角色好感。
- 好感分为五颗心；达到五颗心会解锁角色与玩家的纪念合影。钱包、每位角色好感与图鉴均保存在当前浏览器。
- 重复挑战不会无限刷钱：每个角色只会结算超过该角色历史最佳报酬的差额。

原型边界
- 全部角色均为虚构成年人。
- 九位人物写真均为 AI 生成的虚构成年角色，不对应真实人物。
- 本作中的“男娘”是玩法规则：男性虚构角色以女装或明显女性化造型出镜即计入，不以角色的自我称呼为准。
- Demo 不主张通过身体特征识别现实人物的性别或性别认同。
- 当前版本含 9 位来访者、9 张 AI 生成的成年日式二次元写真、收藏册、夜间小屋、礼物与好感养成、双人合影解锁、掌印反馈与单局结算；无服务器、广告与真实照片。

文件说明
- index.html / styles.css / game.js / assets：GitHub Pages 完整运行包，缺一不可。
- START_GAME.html：可选的离线单文件试玩入口，不需要上传到 GitHub Pages。
