# 调杯弹珠版设计说明

## 本版验证什么

把局外弹珠机做成一次很短的“开局调杯”：玩家先选投放口，再用两次吹气对随机结果做有限干预，最后带着配方进入原来的俯视弹跳局内。它不是纯抽奖，也不会代替局内操作。

## 一局流程

1. 左、中、右三选一投放团子弹珠。
2. 下坠过程中撞击冰块、奶盖、爆珠、柠檬、吸管、布丁等配料。
3. 玩家可吹气两次，微调弹珠方向；每个特殊配料一局只结算一次。
4. 撞击记录与最终落入的杯槽共同生成配方，最多保留两个不同效果。
5. 若撞到黑糖，会出现可拒绝的“怪味契约”：前两次有效落点方向反转，但成功落地的糖晶奖励提高。
6. 带配方进入局内；局内原有能力三选一仍会正常出现，同名效果只刷新时长，不叠加倍率。

## 当前配料效果

- 冰块：回落重力 -15%，持续 3 次有效落点。
- 奶盖：平台半径 +12%，持续 3 次有效落点。
- 吸管：横移速度与加速度 +12%，持续 3 次有效落点。
- 爆珠：峰高 +10%，持续 3 次有效落点。
- 柠檬：靠近平台时获得弱牵引，持续 3 次有效落点。
- 布丁：保证出现高收益落点，持续 2 跳。
- 黑糖怪味：自愿选择；前 2 次有效落点方向反转，踩稳后糖晶 ×1.5。

## 控制赌性的边界

- 一颗弹珠、三条起始路线、两次有限干预，玩家能影响但不能完全控制结果。
- 最多带两个效果，避免开局随机结果压过局内技术。
- 普通配方只提供短效增益；负面能力必须由玩家主动接受。
- 首次可选择“原味直冲”跳过弹珠机；失败后默认沿用上杯配方一键重开，重新调杯消耗订单产出的调杯券。
- 当前不接入付费抽取、广告加次数或永久数值成长，先验证它是否让重复开局更有趣。

## 后续可扩展方向

- 每日限定杯底：每天固定一张所有玩家相同的弹珠盘，适合分享路线。
- 配料图鉴：只记录见过的配方和漫画表情，不直接增加战力。
- 主题杯季：把部分钉子替换成芋泥瀑布、摇摇冰、爆爆珠连锁等规则，但每季只突出一个新变量。
- 好友同种子挑战：分享本局弹珠盘种子，比拼同一配方下的最高层。
